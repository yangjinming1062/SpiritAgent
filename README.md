# 唤生 SpiritAgent

### 让想象中的伙伴，来到你的桌面。

**自己创造，持续相处，也能一起做事的 AI 伙伴。**

从一句描述或一张参考图开始，决定伙伴的样貌、性格与声音。它以透明的可动形象住在桌面，记得相处中的信息，按情境主动交流，拥有自己的动态与日记；需要做事时，也能使用本机工具协助你完成任务。陪伴是唤生的核心，工作能力是相处的延伸。

## 功能与特点

### 从一颗蛋开始，创造自己的伙伴

唤醒桌面上的蛋，为伙伴取名，描述物种、性格、关系与说话方式；依次确认头像、全身形象和音色。外貌既可以由 AI 结合文字与参考图生成，也可以直接上传自己的图片。它可以是人、动物或自创生灵，身体结构与材质由你的设定决定。

确认全身形象后，默认动作与初始房间在后台准备，不打断后续引导。以后可以修改性格、说话风格和声音，通过衣柜设计、微调与更换着装，通过场景库创建或上传新的环境壁纸。核心身份由你决定，互动记忆不会擅自改写角色设定。

### 有形象，也有自己的表达

伙伴使用透明图片姿态与视频动作呈现，可拖动、缩放，在屏幕边缘或窗口旁栖息。拖拽、长按与文件拖入有即时反馈；自主状态下可陪工、漫游或靠近交流。动作库随着装切换，伙伴可以提出并制作新的表达动作，制作完成与实际表演分别处理。

对话支持文字、语音、图片与视频。日常台词逐句成泡，语音可带情绪与段内演绎；语音按顺序交付，可暂停、续听与重播，本机保存已听状态和断点。图片直接查看，仍在生成的视频以等待卡片显示，完成后更新原卡片。语音合成失败时保留台词，形象尚未可用时保留蛋形与真实准备状态。

### 在相处中积累记忆与生活

长期记忆让伙伴在后续交流中参考你的偏好和经历。你可以按用途查看记忆、检查依据、编辑或遗忘；陪伴、文案秘书和语言老师各有独立记忆，避免生活资料与任务经验混在一起。

生活动态是一条独立时间线：伙伴可发布文字、图片、视频或语音，你可以在评论里继续交流，也可以在对话中请求发布。夜间整理会回顾交流、动态互动和已完成活动，更新相处理解，并自主决定是否写第一人称日记。日记发布后只读，后续可按日期或话题聊起；动态与日记均有未读提醒。

### 主动陪伴，由你控制距离

伙伴可以记下有目的的等待，到了合适时间或情境再判断是否联系，也可以选择安静。重连与解锁不会自动补一句问候，过时安排不会强行兑现。

| 档位 | 在线主动表现 |
|---|---|
| 自主 | 可主动文字、语音、情境动作与移动 |
| 常规 | 原地轻量文字联系 |
| 静止 | 停止实时主动联系、发声、表达与移动，仍响应用户操作 |

全屏等沉浸情境可临时静止，右键菜单还提供 50 分钟的“临时安静”。夜间生活、动态创作、自主换装与场景变化有各自开关或锁定选项；静止档不关闭普通自动化、记忆整理或所有后台创作。

### 闲聊、生活与工作，各有入口

| 入口 | 适合做什么 |
|---|---|
| 轻语 | 双击桌面伙伴展开，随时说几句，不必打开完整窗口 |
| 生活空间 | 陪伴聊天、查看动态与日记、管理衣柜、场景、记忆与渠道 |
| 工作台 | 使用文案秘书、语言老师或普通工作会话，查看工具过程、推理与运行轨迹 |

生活空间和工作台可在内容面板旁显示伙伴，拖动伙伴即可移动整个窗口。主题提供日色、夜色与透明样式，可调整伙伴大小、显示方向、自动朗读和快捷键。

Windows 另有桌面模式：把场景壁纸、伙伴、轻语、对话与各功能面板放进桌面，面板可移动、缩放和最小化。Dock 支持固定应用、排序、查看运行窗口、切换与正常关闭程序；多屏可指定交互屏，其余屏展示背景。退出桌面模式时恢复系统任务栏、图标与工作区。macOS 使用窗口模式。

### 一起完成任务，也能跨端联系

伙伴可借助 Runner 使用终端、文件、浏览器与屏幕操作等本机能力。工作台保留工具过程和结果，Skills 扩展具体工作方法，学到的技能按用户与预设分开保存。定时自动化使用独立任务会话，云端部分可在桌面离线时运行，本机步骤仍需电脑在线。

打开桌面的「远程」并用手机扫码，即可在浏览器访问当前账户的专属页面，与桌面共用对话、人设、记忆和生活空间。手机可聊天、查看动态与日记、管理记忆、场景和衣柜；电脑离线时仍可云端聊天，电脑与执行器在线时可调用本机工具。已授权手机可在桌面随时撤销。

## 开始使用

唤生目前需要自行部署后端并配置模型服务。桌面应用与安装器支持 Windows、macOS，后端运行在 Linux Docker 容器中。聊天、图像、视频、语音等能力依赖相应供应商配置，外部服务按供应商规则计费；部分能力可接本地模型服务。完整体验还需要可用的本机 Runner 环境。

已有安装包时：

1. 运行唤生安装器，准备桌面应用、Python 与 Runner。首次安装需要联网获取运行环境和依赖。
2. 在客户端填写后端服务地址与激活码；激活码由后端管理员创建。
3. 唤醒蛋，完成角色、头像、全身形象与音色确认，开始相处。

账户可从托盘添加、切换与移除。管理员可管理用户、模型能力、额度、更新包及分组备份恢复。Windows 更新由用户检查、下载并确认重启；macOS 当前使用安装包更新。

本机工具以当前用户权限真实操作文件、程序和浏览器，停止回合不会撤销已执行步骤。文件、截图与工具结果可能进入所配置后端和模型上下文；应连接可信后端，并按需要开启工具集与批准跨端对端。

### 从源码启动

准备 Docker Compose、Node.js 24 与 pnpm 11.5.2；版本约束以 [client/package.json](client/package.json) 为准。使用本机工具前，先通过安装器准备 Runner 环境；单独启动客户端不会安装它。

1. 在后端目录准备配置：

   ```bash
   cd backend
   cp config.toml.example config.toml
   cp .env.example .env
   ```

   修改 `config.toml` 中的 JWT 密钥、资产签名密钥与管理员密码，三者均不能保留示例值；在 `.env` 填写 PostgreSQL 凭据，详见 [后端部署](backend/README.md#docker-compose-部署)。
2. 在 `backend/` 启动后端与数据库：

   ```bash
   docker compose up -d --build
   ```

3. 打开 [本地管理端](http://localhost:10620/admin/)，用配置的管理员账号登录。配置供应商信息与所需能力链，再创建用户并获取激活码。对话是交流入口，图像、视频、语音识别与合成等按所需体验配置；未配置的能力无法使用。形象与动作制作还须在后端数据卷准备抠像模型，镜像不会自动下载，准备方法见 [后端部署](backend/README.md#部署与排障)。
4. 另开终端，在仓库根运行：

   ```bash
   pnpm --dir client install
   pnpm --dir client dev
   ```

5. 在客户端填写激活码，完成伙伴引导。

默认 Compose 只在本机回环地址提供后端 HTTP。远程客户端需要公网 HTTPS 入口，仓库提供可选 Caddy 部署配置，步骤见 [部署与排障](backend/README.md#部署与排障)。自行构建安装器、更新包及检查命令见 [构建与发布](scripts/README.md)。

Windows 开发桌面模式前需构建原生宿主，见 [桌面宿主构建](client/desktop-host/README.md#构建)。完成伙伴准备后，可从生活空间或工作台顶栏、精灵右键菜单或托盘“呈现方式”进入桌面。
