视频的创建段主要为 2.5 倍速，功能页按讲解停帧，桌面动作保留实机画面；口播由 MiMo 合成并配字幕。

七张 PNG 均于 **2026-10-26** 在 Windows 上采集，组件源码为提交 `9f8bc531`，使用 Electron `42.7.1` / Chromium `148.0.7778.280`、1 倍像素比例。仓库外临时 Vite 入口渲染 [MainRoot](../../client/renderer/app/windows/main/main-root.tsx)、[DesktopRoot](../../client/renderer/app/windows/desktop/desktop-root.tsx)，复用当前页面与样式，以本地桩替换 IPC 和后端；通过 Electron 捕获页面，没有重画控件或修改产品组件。

账户、对话、事项、时间与成果引用均为人工编排的虚构示例，阅读链接使用 `example.com` 占位；头像与生活区静态形象均使用[仓库图标](../../client/assets/icon.png)占位。动作定义直接取自当前[内置目录](../../backend/features/action_library/presets.py)。采集时切换页面、主题与会话，展开阅读笔记、滚动详情，并移动和缩放桌面面板；未读取真实账户、调用供应商或启用 Windows Explorer 接管。

PNG 覆盖当前生活浏览、事项详情与成果入口，不证明记录中的阅读、创作或跨日活动真实发生，也未验证成果打开后的内容、原生桌面行为、视频播放或手机实机界面。旧视频尚未覆盖这些生活页面；长期生活、模型质量和平台验收仍需各自验证。

更新时从当前组件或实机重新采集，不手工重画未实现界面；注明平台、版本、时间、真实／虚构数据、人工介入和失败范围，并同步根 README。跨日生活展示应可追溯实际记录和成果。清除账户标识、密钥、激活／配对码和私人内容，检查可读性与链接；除已配置豁免的 `demo.mp4` 外，文件须满足仓库 1000 KB 检查。
