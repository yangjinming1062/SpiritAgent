# 产品展示素材

本目录存放 GitHub 首页使用的产品示意图与实机演示。

| 文件 | 来源与覆盖范围 |
|---|---|
| [overview.svg](overview.svg) | 手工产品概览；非运行截图，无外部图片、字体或脚本依赖 |
| [demo.mp4](demo.mp4) | 2026-10-20 Windows 录屏剪辑，3 分 45 秒、1920×1080、30 fps；覆盖创建、功能页、桌面模式与动作预览，原录屏无可核实构建号 |

新增截图须区分真实账户与虚构数据，注明平台、构建、采集时间和人工介入。示例数据不证明真实阅读、创作或跨日生活；跨日展示须能追溯实际记录和成果。
