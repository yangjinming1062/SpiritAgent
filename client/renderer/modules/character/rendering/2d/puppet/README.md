# Puppet 2D 渲染

将 PSD 与扶边姿态包装配为可交互 2D 角色。依赖与水合见 [Renderer](../../../../../README.md)，资产契约见 [PIPELINE](../../../../../../../docs/PIPELINE.md#6-2d-分层动画能力链)，自然度验收见 [DESIGN](../../../../../../../docs/DESIGN.md#23-2d-路径下的多层动画叠加)。

## 边界与装配

`vendor` 保留 Anime2.5DRig 上游实现和许可证，不参与仓库 lint / format；不复制 PuppetLoom 的 AGPL 代码或文字。

[vendor-loader.ts](vendor-loader.ts)通过 Vite 资源 URL 加载并等待经典脚本；[puppet-runtime.ts](puppet-runtime.ts)处理上游类型与素材适配；[PuppetStage.tsx](PuppetStage.tsx)只组织输入和生命周期，不承载几何算法或供应商请求。

加载、装配和替换遵守取消代次，失败向宿主报告，不保留假就绪实例。

## 素材与几何

### 层名、侧别与遮挡

装配统一规范层名、侧别和节段，补齐眼与四肢锚点。只在头部相关已占槽位内调整遮挡，身体和服装保留 PSD 原序。

原始单嘴层作为闭合层，开口由纹理派生；显式 mouth_open / mouth_close 不走派生路径，通用嘴只在原始与闭合素材均缺失时兜底。

绑骨左右按屏幕几何判断，不直接采用素材命名。腕踝锚点取可见像素，整肢与分段共用关节切线，蒙皮只混合相邻骨骼。

### 头部、身体与网格

[artmesh.ts](artmesh.ts)沿透明轮廓建网格，退化时用四边形；命中仍检查纹理 alpha，不把三角形或包围盒全部视为身体。

头部控制笼与身体骨骼分离，颈上随头、下随躯干，身体复用已平滑偏航，不二次缓动；全身变换不二次叠到头部。转头映射保持单调，远眼以几何收窄，不用透明度伪造；远侧挂件淡出不能套到眼眉。

中立几何保持恒等，骨长和左右弯折受约束，超距目标连续钳制。袖口影响局部衰减，衣身和裙摆保持躯干归属；实现见 [skeleton.ts](skeleton.ts)、[skin.ts](skin.ts)。

### 素材分档与限制

`segmented / sided / blob` 表达肢体素材能力，`semantic / grouped / minimal` 表达整体机制完整度，两者不能混用。缺少眼部素材不降低全身动作档位；仅缺脸或层数不足时进入 minimal。
眼部只有在同侧眼白、眼锚点与非合成闭眼层齐备时才执行淡入淡出和局部眼动；
否则保留原始开眼纹理，避免露出供应商灰色脸底，不影响转头和四肢动作。

整肢只能近似平面屈伸，不能重建缺失抓握、遮挡或侧身透视。自动绑骨依赖自然站姿，交叉肢体、缺失补全和服装未分层须限制动作；额外部件不能只凭层名承诺动画。

## 驱动与确定性

[actions.ts](actions.ts)、[gait.ts](gait.ts)、[drag.ts](drag.ts)共同生成当前帧。接触与悬挂优先，其次手势、步态和呼吸；未参与动作的肢体保持自然，不被低优先级通道拉走。

支撑脚补偿实际位移，停步平滑回中立；拖拽固定按下时抓取点，最终顶点同时用于呈现和命中。头发根部、裙摆腰线和双手接触保持约束，降低动态减小惯性。

自主观察使用种子化段落，不逐帧抽随机数；动作期间暂停观察时钟。嘴型只消费实际音频振幅，停声回到当前情绪嘴型，不能描述为音素同步；显式视线目标优先，清理后恢复观察。2D 完整消费动作队列，不为迁就其他渲染路径只执行首项。

`advanceSim`、`snapshot`、`forceBlink` 和 `frozen` 用于可重复验证；冻结须停止相位与调度，不只是停止绘制。`poseSafety` 报告翻转和拉伸，不自动限制动作。验证中立恒等、极限姿态与连续过渡后，仍须单独验收自然度。

## 扶边与预览

[edge-pose.ts](edge-pose.ts)兑现接触形变，外层舞台保持水平；命中从最终三角形反查纹理透明度，隐藏 PSD 不捕获鼠标。旧包控制区降级遵守 PIPELINE，不复制另一套资产判断。

左右纹理分别有限重试，换包或卸载取消重试；错误记录侧别和阶段，不能被 PSD 加载成功掩盖。

[AssetPackPreview.tsx](AssetPackPreview.tsx)使用独立运行时，共享动作定义但不共享桌面情绪、队列、命中或空间状态。仅可见且播放时推进，暂停保留帧，卸载释放；预览接触对齐取景框，桌面对齐真实窗口边缘。

姿态侧预览分贴边效果与完整素材两个查看模式：前者沿用容器边缘模拟，确认探身动作与接触关系；后者按原始纹理等比展示，配合深浅底检查全身构图与透明轮廓。
