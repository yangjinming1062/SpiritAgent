# Puppet 2D 渲染

本目录把分层 PSD 与扶边姿态资产装配为可交互的二维角色。渲染层依赖和水合入口见 [renderer README](../../../../../README.md)，资产描述符与完整发布条件见 [PIPELINE §6](../../../../../../../docs/PIPELINE.md)，动作自然度的产品验收见 [DESIGN §2.3](../../../../../../../docs/DESIGN.md)。

修改装配读“素材与几何”，修改动作读“驱动与确定性”，修改扶边或衣橱展示读“扶边与预览”。参数值、层名目录和公式以链接的源码为准。

## 边界与装配

- `vendor/` 保留 Anime2.5DRig 上游实现及许可证，不参与仓库 lint / format。借鉴其他机制时不复制 PuppetLoom 的 AGPL 代码或文字；本目录按既有许可证边界维护。
- [vendor-loader.ts](vendor-loader.ts)使用 Vite 资源 URL 加载经典脚本并等待就绪；不能依赖 HTML 裸脚本或未完成的全局初始化。
- [puppet-runtime.ts](puppet-runtime.ts)在装配边界处理上游全局类型、层名与锚点。[PuppetStage.tsx](PuppetStage.tsx)负责输入、资源与生命周期，不能把几何算法或供应商请求放入挂载层。
- 同一资源的读取、装配与替换遵守取消和清理代次。失败需向上反映就绪状态，由宿主选择可用形象，不保留一份假成功的运行时。

## 素材与几何

### 层名、侧别与遮挡

PSD 的侧别后缀和四肢节段名可能不命中上游槽位。装配时统一规范名称，补齐眼、四肢锚点与开眼层淡出标记，否则会无声丢失虹膜、远眼、眉毛或耳部机制。

只在头部五官与前发已占用的槽位内稳定调整遮挡层序；身体、四肢、服装与配饰保留原始 PSD 顺序，不能为修正脸部而重排全身。具体头部层序见 [skin.ts](skin.ts)。缺少闭眼素材时保留上游通用部件合成与染色适配。

see-through 只拆出单一原始嘴层，装配边界将其归为闭合层（立绘画风的常态闭嘴即原始嘴形），开口帧由闭合纹理唇线以下纵向拉伸派生；显式提供 `mouth_open` / `mouth_close` 分层的素材不走该路径。通用闭嘴贴图只兜底既无原始嘴层、也无闭合层的素材。

骨架左右以屏幕坐标为准，四肢由几何位置归侧；素材名可能按角色自身左右命名，不能直接决定绑骨。腕踝锚点取可见像素，髋膝位置参考腿部图层；整肢和分段素材使用一致的关节切线，蒙皮只混合相邻骨骼。

### 头部、身体与网格

- [artmesh.ts](artmesh.ts)沿透明轮廓构网格，退化层回退四边形；域外三角形由纹理透明度遮蔽。命中仍需检查实际透明度，不能把整个三角形或图层包围盒算作身体。
- [head-cage.ts](head-cage.ts)与身体骨骼独立。头部五官和发束保留控制笼与弹簧链，身体使用骨骼蒙皮，颈部上下分别跟随头与躯干；全身变换不得二次叠加到头部。
- 转头使用有界边缘斜率，保持局部映射单调，避免纯圆根在边缘造成折叠。脸面深度只作用于面部表面；远眼收窄是几何压缩，不通过透明度伪造。耳等远侧挂件可淡出，眼眉不套用同一淡出。
- 颈上端随头、下端随领口，身体使用已经平滑的头部偏航，避免第二次缓动产生脱节。中立姿态几何保持恒等，机制修改以同种子、同参数可复现为基线。
- [skeleton.ts](skeleton.ts)与 [skin.ts](skin.ts)保持骨长和左右镜像弯折约束；超距目标连续夹到可达范围。袖口影响在肩部附近沿两轴衰减，衣身和裙摆仍随躯干，不能让整件衣服被手臂拉走。

### 素材分档与限制

[limb-split.ts](limb-split.ts)区分 segmented（独立肢节）、sided（左右整肢）和 blob（整体）能力；运行时另按语义完整度选择 semantic、grouped 或 minimal 档。两类分档分别控制四肢和整体机制，不能混用或仅按文件存在判断完整可动。

整肢立绘只能近似平面屈伸，不能恢复缺失的手指抓握、肩部遮挡和侧身透视。自动绑骨以自然站姿为前提；交叉四肢、补全缺失和衣身未分层限制动作幅度。尾部、头饰等额外弹性部件不能仅凭层名承诺独立动画。

## 驱动与确定性

[actions.ts](actions.ts)组织动作包络，[gait.ts](gait.ts)处理步态，[drag.ts](drag.ts)处理悬挂反馈。它们组合到当前帧，遵循以下约束：

- 拖拽悬挂与扶边接触优先；自由状态下手势优先于步态，步态优先于呼吸。未参与手势的手臂保持自然下垂或对侧摆动。
- 行走的支撑脚补偿实际位移，摆动脚抬起；停步后平滑衰减回中立姿态，不能直接清零造成跳变。
- 拖拽以按下时保存的抓取点为支点，惯性衰减与松手回正连续；整体变换作用于头身最终顶点，命中使用同一结果。降低动态偏好缩小惯性幅度。
- 发束根部跟随角色，末端保留惯性；裙摆腰线固定，耳部与呆毛事件最终回中立。自主观察使用种子化段落，动作间回正，不每帧重新抽随机值；动作包络期间暂停观察计时。
- 嘴型只由实际 TTS 振幅驱动，静默后恢复当前情绪预设的嘴型；没有 TTS 就不出现说话嘴型。当前没有音素流，不能把振幅口型描述为音素同步。视线优先消费显式目标，缺失后恢复指针或自主观察。
- 2D 按动作队列顺序推进，不能为了兼容只消费首个动作的 3D 路径而丢掉后续动作；情绪只映射到已有面部参数。

`advanceSim` 固定步进、`snapshot`、`forceBlink` 与 `frozen` 提供可重复验证入口；冻结需同时停止呼吸相位和事件调度，单停绘制不等于姿态确定。

`poseSafety` 在当前参数下报告三角形翻转与最大拉伸，排除亚像素边缘退化；报告本身不自动限制 LLM 动作幅度。修改几何或动作时检查中立恒等、极限姿态、连续过渡与降档结果，再按 DESIGN 做视觉验收；骨骼到达目标不能代替自然度验收。

## 扶边与预览

扶边使用独立姿态包与 [edge-pose.ts](edge-pose.ts) 的参数化形变。生成目标、可加载约束与质量取舍归 [PIPELINE §6.2](../../../../../../../docs/PIPELINE.md)，运行时遵循：

- 扶边接触由本渲染器兑现，外层舞台保持水平。命中用当前形变三角形映射回纹理透明度，隐藏 PSD 和透明留白不挡住鼠标。
- 左右纹理加载分别有限重试，最多三次，间隔一秒、两秒；换包或卸载取消未执行重试。错误记录侧别与次数，描述符解析失败和双手区域降级分别记录，避免被普通 PSD 成功日志掩盖。
- [AssetPackPreview.tsx](AssetPackPreview.tsx)使用独立运行时，与桌面共享动作定义，但不共享情绪、队列、命中总线或空间状态。
- 只有预览可见且播放时推进时钟，暂停保留帧，卸载释放资源；预览扶边对齐取景框，桌面扶边对齐窗口边缘。
