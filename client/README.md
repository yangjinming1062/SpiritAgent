# Client

## 1. 职责与边界

桌面形象载体与可信本地枢纽：负责窗口、渲染、凭据、协议中转、Runner 生命周期和自更新；对话推理归后端，本机工具执行归 Runner。全局边界见 [ARCHITECTURE.md §1](../docs/ARCHITECTURE.md)，体验见 [DESIGN.md](../docs/DESIGN.md)。

## 2. 设计意图

- 伙伴呈现层与可信枢纽共享主进程，但渲染层只经 IPC 使用凭据与 Runner 能力，避免体验代码侵入安全边界。
- 生活空间与工作台复用对话表面及同一连接的数据流；切换窗口不应中断回合，各窗口运行时状态仍需分别水合。
- 已就绪形象优先从本地缓存呈现，新字节就绪后替换，网络失败不能抹掉当前形象；具体缓存与降级约束见 §4。
- 窗口、动画与播放属于客户端投影；打扰档位的权威归属见 [ARCHITECTURE.md §5.1](../docs/ARCHITECTURE.md)，产品规则见 [DESIGN.md](../docs/DESIGN.md)。

## 3. 架构地图

- `main/` 是可信主进程，持有凭据、窗口与 Runner 生命周期；`renderer/` 承载各窗口体验；`shared/ipc/` 定义跨进程通道、载荷与运行时常量。
- 主进程由 tsup 构建，渲染层由 Vite 构建；preload 格式约束见 §4。
- 渲染层分四类：`app/`（应用组合层——bootstrap 装配、runtime 网关路由与宿主分发、workflows 跨模块流程、windows 三窗口体验与 onboarding 引导）、`modules/`（可复用业务能力——conversation 会话、character 角色呈现（含 `rendering/2d`、`rendering/3d` 渲染域）、speech 语音、media 媒体、memory 记忆、room 房间）、`shared/`（无业务共享代码）、窗口入口（根目录 `main.tsx`、`sprite-entry.tsx` 与 `app/windows/*/*-entry.tsx`，保持薄入口）。跨进程契约仍在 `shared/ipc/`（`@ipc`），与 renderer 内的 `shared/` 职责不同。
- 依赖规则：业务模块互不导入、不依赖 app（例外经 ESLint 白名单：conversation → media 的展示原语只读；character 渲染域可订阅 speech 口型振幅）；app → modules 只走公共 barrel；runtime / workflows 不得反向导入 windows；shared 不反向依赖任何业务。
- 会话与形象 / 语音的接缝是注入式端口：形象状态、TTS 与媒体查看器经 `shared/presentation-ports`；语音条播放状态与控制经 `modules/conversation/voice-link.ts`。实现由 `app/bootstrap/bind-presentation.ts` 在各窗口入口渲染前显式绑定（不依赖 barrel 副作用导入顺序）。角色表现命令当前仍经端口下达，收敛为表现输入属后续批次。
- 网关事件由 `app/runtime/gateway-event-router.ts` 只做分派与守卫（鉴权 pending 丢弃、session_id 闸门、代理窗过滤），状态更新按能力在 `app/runtime/handlers/` 组织：会话回合、角色 / 形象 / 衣柜、通知投递与宿主专属 tool.call 分发（含重放去重与仪式行走）。
- `app/windows/sprite/whisper/` 是精灵窗内的轻语卡片浮层（不是新窗口），与 conversation 对接；详见 §4 关键设计决策。
- 窗口入口直接装配对应根组件（`app/windows/*` 的 entry）；生活空间与工作台互不依赖。ESLint 对模块边界实施检查。

## 4. 关键设计决策

### 窗口、连接与输入

- preload 输出 CJS / `.cjs`，主进程输出 ESM：沙盒 preload 不按 ESM 解析，混入 import 会令整个渲染桥失效，包括激活入口。
- 主进程集中裁决生活空间 / 工作台互斥开窗并保存上次入口；工作台精灵和工位位于同一物理窗口，避免跨窗口同步漂移。表面打开时收起桌面舞台、暂停桌面走位；产品布局见 [DESIGN §6.1](../docs/DESIGN.md)。
- 网关宿主—代理：桌面精灵宿主持唯一 WS，其他窗口经主进程代理共享连接，避免各自连接互相顶号及复制重连逻辑。宿主独占 Runner 工具执行，前台表面负责语音；每个窗口连接后自行拉取斜杠目录，内存状态不能跨窗口直接共享。
- 连续性：序列号去重、确认与重放见 [PROTOCOL §0](../docs/PROTOCOL.md)；普通会话切换不重置水位，服务端重启或序列失同步才重置。
- 透明精灵须同时设置窗口透明与首帧 body 透明，否则背景覆盖桌面。生活空间 / 工作台用无边框透明外壳，CSS 负责圆角和阴影；系统亚克力矩形底会污染圆角和伴工外侧透明区。
- 鼠标穿透只有窗口级开关：精灵和弹层登记可见矩形，由统一命中机制切换捕获；弹层不能整窗抢占，否则其他桌面应用不可操作。工作台仅可见本体及标题栏参与整体拖拽。
- 弹层共享拖拽、持久位置与互斥入口，命中区域随位移更新；精灵内弹层使用应用面板头与关闭 / Esc，入口窗口使用主进程统一调度的最小化、最大化和关闭控件。
- 单显示器接力：精灵窗只覆盖当前显示器工作区，跨屏时平移新旧原点差，拖拽基准不动；判别在途指针所属坐标空间，避免二次平移。保存窗口原点与精灵位置，恢复先贴屏再定位；拔屏回最近屏，避免全虚拟桌面带来的 DPI 与命中复杂度。
- 激活入口：未认证立即展示激活浮层；托盘唤起须经 IPC 修改渲染状态，仅拉起窗口无法重开已关闭浮层。
- 全局快捷键由主进程注册，配置进本地镜像与云同步；冲突或注册失败返回状态并降级。Windows 并行调试可用 `SPIRITAGENT_DESKTOP_DISABLE_SINGLE_INSTANCE_LOCK=1`。
- 关闭行为：Windows 隐藏到托盘，macOS 隐藏窗口但保留 Dock 图标。
- 会话参数面板显示后端返回的生效值，“恢复默认”清除会话覆盖后读取后端生效值；重连重放同样刷新参数，切换会话清空参数缓存并重建面板，避免待保存参数跨会话写入。保存响应只水合当前会话的最新修改，失败必须提示；工作台默认保存后刷新当前会话的生效参数。
- 工作台只在当前会话确认不属于陪伴预设时挂载对话面板，避免切换或深链水合期间暴露陪伴参数入口；推理配置作用域见 [PROTOCOL §2.4](../docs/PROTOCOL.md)。
- 轻语卡片是精灵窗内的浮层，不是新窗口：双击精灵切换；主动消息 / 媒体提示 / 视频完成通知点击打开；单击精灵身体是戳击；纯图片或视频投喂进轻语，混有其它文件时整批进生活空间。生活空间或工作台打开时自动隐藏。只渲染聊天气泡与输入，不带参数面板；会话固定为唯一的陪伴会话，打开时消费未读。跨窗口投喂经主进程信箱转交，避免各窗口内存状态互不可见导致附件丢失。

### 状态、凭据与媒体

- 激活码加密持久化，会话 JWT 仅内存并主动刷新，每次启动重新激活；避免持久会话令牌的泄露与过期管理负担。凭据规则见 [PROTOCOL §5.3](../docs/PROTOCOL.md)。
- 配置写入按镜像原子写 → 推 Runner → 防抖上传执行；换号时不信任残留镜像，不能上传旧用户配置。离线编辑恢复后仅播种云端缺失键，多端按保存先后覆盖，不做合并。云端专用的推理 / 语音键不入镜像；白名单与机密边界见 [PROTOCOL §2.4 / §5.3](../docs/PROTOCOL.md)。
- 自更新分预取校验与新进程应用两阶段，失败回滚，避免网络中断或进程被杀时覆盖运行文件；契约见 [PROTOCOL §5.5](../docs/PROTOCOL.md)。
- 生产渲染禁止裸 fetch：相对签名 URL 在 Vite / file origin 下不能正确解析，数据与资产统一经主进程 IPC；确需直连的例外逐行 lint 注释说明 URL 来源。
- 头像用主进程磁盘缓存，2D PSD 叠加 OPFS，3D GLB 用磁盘及 OPFS；衣橱另持久化列表元数据，立绘与描述符、PSD、扶边纹理共用主进程磁盘缓存；首次读取列表后顺序预取资产包，按磁盘预算淘汰。内容哈希命中直接读盘，衣橱不可变路径通过 `preferCache` 同样跳过网络，普通无哈希请求仍可条件刷新。旧缓存先呈现，新字节就绪才替换；网络失败保留旧形象，鉴权失败走会话过期，登出清除渲染及主进程形象 / 模型缓存。
- 对话与片刻共用媒体播放入口，视频及配音从资产字节生成正确 MIME 的临时 URL，卸载回收。未读提醒按会话本地持久化并同步窗口，仅对话可见时清除，不能把收到推送或气泡消失算已读。
- 每个可打开媒体的窗口独立挂载预览层，点击卡片在当前窗口查看，点击遮罩或 Esc 关闭。助手正文的 `MEDIA:` 交付标记在流式投影及历史水合时移除，不进入显示、复制或 TTS；流式暂存原文以处理跨增量标记，媒体仍只消费结构化媒体列。
- STT / TTS 经主进程调用云端，无本地引擎；STT 并发与令牌桶限流，TTS 有界排队、合并在途请求并限制云端间隔，超额快速失败。缓存命中不排队、不占额度。
- TTS 使用独立朗读文本：过滤媒体标记、URL、Markdown 装饰及 XML/HTML 标签；仅标点、符号或表情的消息保留文字，不显示播放按钮或语音条，也不合成。标签内部文字不按标签名称推断用途或删除。正常句内标点保留，合成及语音时长缓存统一使用清理后的文本，避免命中旧的异常读音；聊天与转写原文不受影响。
- 气泡结束即可用提前送达的演绎描述合成语音；生活空间始终语音由前台代理拉取、落盘并投影语音条，不修改后端消息。交付及缓存约束见 [PROTOCOL §1.4](../docs/PROTOCOL.md)。
- 运行轨迹、推理折叠、两端气泡变体与时间分隔条均由现有消息状态投影，不另写正文或后端接口；连发合并与冲刷时机见 [DESIGN §6.6](../docs/DESIGN.md)。 待发队列在提交时合并文本与附件，对应一个用户消息 id；打字和组字重置计时，完成事件不能越过仍有效的计时器。陪伴历史按空行还原气泡并共享回复 id，推理仅留首段、媒体仅留末段。
- 每次连接上报 IANA 时区，夜间政策开关按房间、衣橱、交互场景归位并直接读写服务端；不复用白天打扰档位。日期与夜间媒体契约见 [PROTOCOL §1.2](../docs/PROTOCOL.md)。

### 视觉、兼容与功耗

- 应用图标以 `assets/icon.png` 为母图，保留真实透明通道；替换时同步导出同目录的多尺寸 ICO、ICNS 与 `installer/src-tauri/icons/` 中的安装器图标，否则安装后仍可能显示旧图。导出不得铺底色。
- 窗口控件统一消费 `shared/panel` 与 `--ui-*` 语义 token；CSS 持有底色，主题注册表只存展示信息。根节点主题同时切换色彩与效果轴，新增控件不得硬编码颜色。
- 主题设置在生活空间；本地缺失或未知主题回落日色透明，入口 HTML 同步声明该主题。精灵瞬时浮层使用独立 overlay token，不继承清透窗壳低透明度。
- 玻璃采样：生活空间直接模糊房间图后覆 tint，因为兄弟层 backdrop-filter 不可靠；工作台采样桌面且底板更不透明。降低透明度偏好或集显触发 `.no-blur`，关滤镜并提高底板不透明度，避免大面积合成成本。
- 渲染回退：WebGPU → 内置 WebGL2 节点后端 → 经典 WebGLRenderer → 产品兜底。经典回退必须新建 canvas，已取 WebGPU 上下文的 canvas 无法再取 WebGL2；模型加载等待异步引擎就绪，环境贴图按渲染器类型生成。
- GPU 默认低功耗，避免小型精灵持续唤醒独显；引擎自管活跃、空闲、休眠与停止调度，不依赖 Three.js 固定循环。
- 材质加载保留 GLB 原生贴图，自定义贴图失败回退原生材质；拖拽速度驱动物理倾角和松手回正，基准尺寸随屏幕高度适配。2D 机械反馈见 [renderer 架构指南](renderer/README.md)。
- 下载失败与生成失败分别提供重试入口，水合保持同一分流，避免错误触发付费重生成；契约见 [PROTOCOL §1.2](../docs/PROTOCOL.md)。
- 开发 CSP 允许本地 Vite Fast Refresh 所需的内联脚本和 eval，生产保持严格策略；混用会造成开发白屏或放松生产脚本边界。

## 6. 已知限制

- WebGPU 透明合成依赖预乘 alpha；精灵窗出现黑晕或黑底时走渲染回退并记录开发日志。
- 非默认主题冷启动可能闪一帧浅色，因为入口静态主题与配置镜像可能短暂不同步；精灵窗保持透明。
- 大面积玻璃滤镜成本随面积上升，降级见 §4；生活空间玻璃只能覆盖圆角内部，圆角外及工作台伴工外侧须保持真透明。
