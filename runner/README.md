# Runner

## 1. 职责与边界

执行本机终端、文件、浏览器、代码、进程、多模态、系统感知和 Skills 工具，并探测实际能力。Runner 不装配人格或管理对话，不持有 Backend 登录凭据；模型请求经 Client 代理。

## 2. 设计意图

工具共享环境生命周期而非相互依赖。当前采用高信任执行模式：对端准入与工具集开关构成执行授权，通用终端和文件工具保留本机访问能力，不提供逐次裁决或通用强隔离沙箱。

## 3. 架构地图

```text
server.py → tools → envs → utils
```

`envs` 管本地与 SSH 环境，`tools` 按能力分域，`utils` 提供基础设施；底层不反向导入上层。环境清理与活跃进程检查通过回调衔接，工具集映射在 [catalog.py](tools/toolsets/catalog.py)。

## 4. 关键设计决策

### 连接、配置与能力

Runner 主动连接 Client 的 OS IPC，重连前重读端点和 token。配置仅保存在内存，由 Client 在执行前推送完整快照；传输和调用语义见 [PROTOCOL](../docs/PROTOCOL.md#2-client--runner-契约)。

能力须实际探测系统 API，不以依赖可导入代替可用性。进程启动生成唯一 `run_generation`，重连不轮换；周期探测变化才通知，异常撤销相应能力。当前 Client 尚未完整消费运行期通知与代次，不能据此宣称端到端动态门控已完成。

反向模型调用受 Client 桥实例累计预算限制；Runner 另有单连接守卫，重连只重置后者。工作线程等待主循环，超时取消等待。图片工具结果直接交付主回合，必要时缩图，不先调用另一模型转写。

### 网络、路径与进程

HTTP 统一使用 `httpx[socks]`。SSRF 在 URL 预检和实际建连时均校验；连接已检查 IP，保留原 Host、TLS SNI 和证书校验，每跳重定向重新检查，DNS 解析移出事件循环。

Windows 在启动阶段加入 Job Object 管理进程树，不在模块导入时产生此副作用。真实路径经句柄规范化，处理短名、链接、联接点和未创建后缀，比较忽略大小写并拒绝备用数据流。

本地终端按 Git Bash / Darwin-BSD 提供环境约束并拦截不适用的 Linux 管理命令；SSH 不套本机规则。SSH 密码使用临时 askpass（OpenSSH ≥ 8.4，Windows ≥ 8.9），密钥优先，脚本随环境清理；密码和私钥路径作为本机机密处理。

代码子进程 RPC 使用一次性能力 token，首帧鉴权。依赖与平台 marker 显式声明，不在运行期补装，也不以可选导入掩盖漏依赖。

工具说明随实际能力使用：文件工具不可用或无法访问目标环境时可用终端；代码工具的导入帮助函数不解锁被禁用的能力，`retry` 只重试异常、不判断副作用是否安全。桌面操作的后台支持取决于平台与动作，全局键盘和坐标操作可能影响前台；工具返回调用结果，实际应用效果须由后续状态核实。

### 调用日志与取消

`utils.call_journal` 管原子认领、参数指纹、持有者和终态。取消发生在认领线程未结束时，先等待认领收尾再记录未知结果；完成与取消写入串行，未持有认领凭据不得补写终态。

已保存结果重放不再次裁切，也不执行工具。日志不可写、无调用标识、保留期及 unknown 的处理见 [PROTOCOL](../docs/PROTOCOL.md#25-本机调用日志)；任务取消不证明线程或外部副作用已停止。

### 按预设学习技能

`ContextVar` 固定调用作用域并在结束时恢复。学习技能保存在 `$SPIRITAGENT_HOME/learned-skills/<user_id>/<system_preset_id>`，读取合并本域与静态技能，本域优先。

修改静态技能先复制到当前域，删除只影响本域副本；路径和符号链接不得跨域。社区技能执行威胁扫描和结构检查，技能自带忽略规则只对内置或可信来源生效。平台过滤与学习作用域分别校验，见 [PROTOCOL](../docs/PROTOCOL.md#26-skills-平台声明与过滤)。

## 5. 与外部的契约

Client 负责身份代理、配置推送和生命周期；Runner 负责真实能力与执行结果。协议方法、工具清单同步和反向请求统一见 [PROTOCOL](../docs/PROTOCOL.md)，安装布局见 [Installer](../installer/README.md)。

## 6. 已知限制

调用日志只降低重复执行风险，不保证任意副作用恰好发生一次。删除、发送或写入不能普遍撤销；unknown 需要核对，not_found 也不能证明从未执行。网络和路径检查不把通用终端变成安全沙箱。

## 7. 验证入口

静态检查和 wheel 导入面检查见 [Scripts](../scripts/README.md#8-按改动选择验证)。OS API、路径、终端和进程树在对应宿主验证；SSH 单独验证。调用修改覆盖取消、日志重放与作用域隔离，不能只检查正常返回。
