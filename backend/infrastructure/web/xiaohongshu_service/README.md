# 小红书账户采集服务

此目录在固定上游版本上构建账户隔离接口，复用官方镜像中的浏览器。源码版本、归档校验和补丁入口见 [Dockerfile](Dockerfile)，Python 调用边界见 [xiaohongshu.py](../xiaohongshu.py)。

## 构建与运行

Go 模块签名校验保持启用。`backend/.env` 的 `XHS_BUILD_GOPROXY`、`XHS_BUILD_GOSUMDB` 可覆盖构建源，留空使用 Dockerfile 默认值；直接构建使用 `GOPROXY`、`GOSUMDB` 参数。逗号分隔的代理源只在 HTTP 404/410 时切换，网络超时仍失败；`XHS_PROXY` 只控制运行时浏览器出站代理。

采集服务不设置访问令牌，默认 Compose 不映射宿主机端口，Backend 仅通过容器网络调用。原全局 REST 和 MCP 入口不再注册。所有账户接口设置 `Cache-Control: no-store`，请求正文和平台原始错误不写日志。

`XHS_MAX_BROWSERS` 限制所有扫码和读取浏览器的总并发，默认四个、范围 1–64；等待扫码也占用名额，满额立即返回 `503`，不排队。每个浏览器由独立 launcher 临时目录承载，在成功、失败、取消和超时后关闭进程并删除 profile。读取仅使用本次请求传入的 Cookie，不读取全局文件或共享浏览器登录状态；服务无需凭证数据卷。

## 登录与凭证交付

`login_admin.go` 维护按随机 `owner` 和 `session_id` 绑定的内存扫码会话。Backend 生成并校验连接归属，平台 Cookie 只有后端数据库持久保存。创建新二维码只结束同一 owner 的旧会话，其他账户继续扫码。

二维码有效四分钟。浏览器事件循环归扫码会话，不随二维码 HTTP 请求或客户端页面关闭而结束。查询、短信提交复用同一页面；验证码必须是六位 ASCII 数字，只向同一可见验证弹窗的唯一输入框输入一次。提交最多等待十八秒，不自动重填、重发或重复确认。短信验证、加载跳转及不支持的其他验证分别保留明确状态；错误码区分页面检查、输入、确认和 Cookie 取得失败。

扫码成功后关闭浏览器，内部结果携带当前平台 Cookie，供 Backend 校验并以连接修订作条件保存。结果可重复读取，成功保存后调用取消接口确认清理；未确认最多保留四分钟。取消、替换、到期会清空 Cookie；进程重启不保留会话，Backend 将丢失的会话转为需要重新登录。找不到或归属不符返回 `409`，已过期返回 `410`，不回显请求信息。

搜索固定筛选最新、一天内内容；详情只读取目标笔记且不加载全部评论。每次接口请求之前由 Backend 重新校验账户政策、凭证修订及预算，浏览器内部资源不计为 Backend 接口次数。平台来源、正文和发布时间仍由 Backend 再次校验，服务健康不代表平台登录或检索成功。
