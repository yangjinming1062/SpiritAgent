# 2D 后端模块

2D 形象的完整资产编排器：分层拆分见 [seethrough/](../seethrough/)，姿态生成及发布约束见 [能力链说明](../../../../docs/PIPELINE.md#62-扶边姿态包)。本模块负责生成任务、优先级队列、资产落库、外观激活与就绪事件；另持有 LLM 动作白名单。

## 模块边界与契约

编排层连接分层拆分、姿态生成与优先级队列，完整包校验后才发布并处理外观激活。资产描述符见 [PIPELINE §6](../../../../docs/PIPELINE.md)，状态与事件见 [PROTOCOL §1](../../../../docs/PROTOCOL.md)。

自主动作白名单由 [actions.py](actions.py) 维护，变更须同步客户端动作兑现；不在本说明复制字段和枚举。

## 关键约束

- **3D 用户后台排队的 2D 拆分**：render_mode='3d' 时 priority='low'；render_mode='2d' 时 priority='high'。不同资产任务独立排队，发布时核对当前身份与穿着意图，避免较晚完成的旧任务覆盖用户选择。
- **失败兜底**：生成失败不激活新模型、不自动穿着新外观；已有可用模型继续服务，无可用模型时走客户端渲染级联。
