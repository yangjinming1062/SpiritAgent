# 扶边姿态参考

`left.webp` 与 `right.webp` 是一对左右镜像的灰色人体参考，由 Gemini 生成，无面部、发型与服装细节，用于约束扶边姿态中双手、躯干与头部的相对位置。生成姿态包时，参考图与本次用户立绘拼接为双分区参考图输入生图供应商：立绘承担身份与外观，参考图只约束姿势。参考图本身不下发客户端，交付的是生成并转为透明纹理的姿态图（ISNet 显著性抠图，失败退回色幕色键，见 [matting.py](../matting.py)）；加载性校验与重绘边界见 [PIPELINE §6.2](../../../../../../docs/PIPELINE.md#62-扶边姿态包)。
