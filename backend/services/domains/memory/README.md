# 预设记忆

本域持有记忆召回、证据维护、人工编辑与恢复后的有效性判断。聊天和后台流程通过公共入口使用它，不在调用方复制维护策略。

隔离边界见 [ARCHITECTURE §6.5](../../../../docs/ARCHITECTURE.md#65-记忆隔离边界)。[证据维护入口](memory_learning.py)集中执行原子决策，[存储入口](memory_store.py)承载人工编辑、系统事件及向量回填。应用层和适配层不直接修改记忆。作用域来自认证会话，模型不能覆盖。

## 记忆判断

学习记忆以原子事实保存，长期背景是其中少量明确陈述的视图。onboarding、交互统计、系统已兑现事件与日记由各自入口记录；统计、日记与助手表达不能作为用户偏好的独立证据。取舍、矛盾处理与有效期的统一策略见 [memory_policy.py](memory_policy.py)。

## 来源与并发

证据必须逐字引用同域、上下文水位以上的原始用户消息。发送时间和原文指纹识别分叉复制，重复处理不能增加独立证据。后台同域审核串行；即时提案经独立 LLM 审核，提交时重新核对快照与原文。整批修正原子生效，并发快照失效直接丢弃；格式或证据校验失败只反馈重试一次。LLM 调用不持数据库事务，聊天不等待回合后的审核。

## 完整审阅

会话审核水位只在完整批次成功后推进，零变更也算已检查。原始消息完整装入预算，单条超预算时单独审阅；不能截断正文后推进水位。即时检查优先保留最新消息，再按时间顺序呈现；后台排空待处理消息并轮转检查记忆，补充与新发言相关的记录。若单条消息超过供应商上下文能力，审核失败并保留待处理状态，不静默漏审。

## 修订与遗忘

维护保留近期修订和历史事件指纹。人工编辑移除旧正文证据，但保留遗忘所需指纹；重新保存资料重置旧有效期和维护属性。删除清除正文、修订历史和引用，只留事件指纹，阻止从旧消息或其分叉重新提取；用户后续重新表达可以提供新证据。抑制以整条原始消息为粒度，该消息中的其他内容也不再自动提取。失效撤销错误判断，遗忘响应明确删除请求，不能相互替代。

## 恢复与读取

聊天、伙伴状态和夜间规划只读取有效且未到期的记录；推断必须携带依据类型。模型历史遵守会话上下文水位。备份恢复重映射证据及修订中的引用，重置审核水位并保留遗忘指纹；缺失原始消息的导入判断须失效。管理接口见 [PROTOCOL 的记忆作用域](../../../../docs/PROTOCOL.md#预设记忆与学习作用域)，包级恢复见 [§5.6](../../../../docs/PROTOCOL.md#56-备份校验与覆盖恢复)。

## 召回与降级

向量与关键词 / CJK N-gram 双路召回、RRF 融合，叠加重要性和不归零的时间衰减；写入召回池同步补向量，主对话前自动注入相关记忆。嵌入未配置或维度不匹配时仅降级到同域关键词检索。

## 验证入口

入口分别为[证据维护](memory_learning.py)、[存储](memory_store.py)与[统一策略](memory_policy.py)。修改时围绕受影响的边界检查：跨预设隔离、原文及版本核对、整批原子提交、完整审阅水位、遗忘后重复导入与备份引用重映射。静态检查见 [Backend](../../../README.md#6-验证入口)；只验证查询或样例数据不能代表真实 LLM 审核质量。
