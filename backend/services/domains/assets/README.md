# 正式资产生命周期

汇总业务引用并回收 `companion-assets` 文件。路径、签名、媒体保护和保留期归 [PROTOCOL](../../../../docs/PROTOCOL.md#资产访问与缓存)；本模块负责事务与并发安全。

| 入口 | 职责 |
|---|---|
| [references.py](references.py) | 汇集消息、工具结果、回复、独立资产、任务、目录和待投递事件引用 |
| [lifecycle.py](lifecycle.py) | 事务内释放登记、候选回收、遗漏文件发现及补偿删除 |
| [公共入口](__init__.py) | 提供上层读引用、登记和清理能力 |
| [write_protection.py](../../infrastructure/assets/write_protection.py) | 用户资产锁与未交接写入保护 |

- 删除历史先调用 `collect_message_asset_releases` 登记释放并移除对应媒体事件；行锁顺序为用户源消息、视频任务、助手回复。事务提交后入口先停止对应视频和语音任务，再清理；回滚不删除正式文件。
- `collect_live_asset_paths` 校验账户及完整路径，展开当前与保护期旧目录的引用；目录不可读时停止整个账户回收，不能把读失败当无引用。
- 回收分为待办事务 → 资产锁内一致快照复查/删除 → 结果事务，避免持文件锁等制作业务行锁。PostgreSQL 使用可重复读，防止采纳时引用跨表转移被漏读；文件已删除而结果未提交可幂等重试，失败保留路径、次数及诊断。
- 写入保护继承业务任务，覆盖子工具返回到父回合提交之间；独立后台生成须独立归属。协程完成自动释放，非协程写入显式释放。派生历史和直接复制旧引用的入口必须持同一用户资产锁。
- 可恢复任务、待采纳结果与可重试候选继续持有文件；终态全身候选按生命周期回收。供应商任务的取消由各应用所有者处理，本模块只核查本地引用。

验证命令归 [Scripts](../../../../scripts/README.md)，重点检查回滚、采纳并发、目录读失败、写入未交接窗口和清理重试。
