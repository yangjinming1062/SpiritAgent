# 预设记忆

负责记忆召回、证据审核、人工编辑、遗忘与恢复。调用方使用公共入口，认证会话确定作用域；跨预设与异步继承规则归 [记忆契约](../../../docs/PROTOCOL.md#预设记忆与学习作用域)。

## 入口与数据归属

| 修改任务 | 入口 |
|---|---|
| 审阅调度、模型判断与退避 | [memory_review.py](memory_review.py) |
| 原始证据、批次、提交与水位 | [memory_learning.py](memory_learning.py)、[memory_policy.py](memory_policy.py) |
| 检索与向量补齐 | [memory_retrieval.py](memory_retrieval.py) |
| 存储、人工编辑与遗忘 | [memory_store.py](memory_store.py)、[memory_admin.py](memory_admin.py) |
| 引导资料与叙事投影 | [memory_bootstrap.py](memory_bootstrap.py)、[memory_narratives.py](memory_narratives.py) |
| 模型资料与命名空间 | [memory_format.py](memory_format.py)、[memory_namespaces.py](memory_namespaces.py)、[prompts.py](prompts.py) |
| 导入与重建 | [backup.py](backup.py)、[日记索引](../journal/journal_indexes.py) |

正文、证据、修订、遗忘指纹与向量分开存储，字段见 [记忆字典](../../../docs/DATABASE_FIELDS.md#记忆与证据)。`context` 仅作展示，类别和槽位使用明确字段。管理列表读摘要和计数，详情再加载证据及修订；检索和夜间资料不套管理分页。

后台审阅入口包括回合后、夜间和调度器，共用活跃账户的作用域发现；即时提案经 [native_memory.py](../../workflows/chat/native_memory.py) 提交。`/remember` 保存显式无证据记录，后续按普通召回记忆维护。原始消息和日记只经所属模块公开查询读取。

## 证据与提交

新用户事实必须有同域原始用户消息的逐字证据。子 Agent 的伪用户输入、伙伴叙事、onboarding 和统计不能独立证明新偏好；原文与时间指纹识别分叉副本，重复不增加独立证据。

模型等待不持事务。提交时在作用域写锁内复核整域及目标版本、原文、来源和遗忘指纹，整批原子应用；版本冲突丢弃快照，格式/证据错误允许一次反馈修复。`basis=system` 的伙伴记录可召回，但不进入用户事实审阅和版本比对。作用域锁仅复用当前或活跃祖先事务持有的锁，SAVEPOINT 回滚后重新取得。

后台按消息 ID 连续审至触发截止，完整批次成功才前进水位，零变更也算成功；失败保留该批及后续位置。单条超批次预算仍完整送审，不能容纳时留待处理。输入上限和选词策略以 learning/policy 为准，不能截断原文后仍宣称证据完整。

### 失败退避与批次

退避按作用域及会话在进程内保存，成功清零，账户维护清除；版本冲突和业务守卫停止不计失败。调度和回合后任务据此跳过，夜间仍按每日节奏审阅，其结果更新同一退避；已排队任务的失败不会反复延长尚未到期的退避。参数由 `memory_review.py` 与系统配置维护。

## 修订与遗忘

| 操作 | 必须保留的边界 |
|---|---|
| 人工编辑 | 清旧正文证据但保留指纹；后续自动修改须引用编辑之后的新用户消息，伙伴记录保持系统性质 |
| 个人资料 | 只接收登记字段，在同域锁内复核整批起点版本；空值表示遗忘，版本 0 表示编辑开始时无有效槽位 |
| onboarding 维护 | 只能失效或遗忘原记录；新证据支持的新判断另存，违例整批回滚且水位不前进 |
| 遗忘 | 清正文、修订与引用，保留指纹阻止旧消息或分叉重学；新的用户表达仍可成为证据 |
| 抑制与失效 | 抑制作用整条原始消息；失效用于撤销错误判断，不能代替明确遗忘 |

## 读取、召回与恢复

只读有效且未到期的记忆，推断携带依据。画像通过专用块注入，普通与背景记忆读取完整对应分类，统计不进入召回。伙伴日记和反思槽位由所属业务发布、索引及遗忘；生活事件的系统记忆保留原事件关联。

检索合并向量与同域关键词排名；向量失败或空间不匹配时保留关键词路径，补向量失败不撤销正文。向量空间由实际供应商、端点和模型标识确定，密钥变更不改变空间；检索同时匹配模型、维度和内容版本，不截断或补零。后台补齐重核原文与版本，不改变正文更新时间，维护与停机收敛所属任务。

恢复重映射来源、证据和修订，重置审阅水位，重建向量与日记索引；遗忘指纹、来源与更新时间继续保留。缺少原始消息的导入判断失效，手写记录仍受新证据时间约束。保留范围与包级约束见 [必要历史](../../../docs/DATABASE.md#必要历史) 和 [备份契约](../../../docs/PROTOCOL.md#备份校验与覆盖恢复)。

按 [Scripts](../../../scripts/README.md) 核对证据/版本冲突、整批回滚与水位、退避、人工编辑、遗忘后分叉及重复导入；检索样例和静态检查不能代替真实模型审核验证。
