# 影像库

负责可播放视觉成品、制作工作项、舞台呈现与播放账本。跨端资格、回执和恢复见 [呈现契约](../../../docs/PROTOCOL.md#影像成品与模式隔离)，制作规格见 [组合影像制作](../../../docs/PIPELINE.md#组合影像制作)。

## 资产分类

成品按 `asset_kind` 分三类，共用一份身份与不可变版本结构，差别在冻结输入的判别联合（`snapshot_json.source.kind`）：

| 类型 | 冻结输入 | 用途 |
|---|---|---|
| `actor` | 身份 + 造型 + 动作，不绑定环境 | 透明主体动画；窗口精灵直接播放，桌面合成到环境层；版本另存主体元数据 `body_json`（遮罩/首末帧/锚点/命中区域） |
| `scene` | 单张环境素材 | 环境媒体；静态图即素材本身，循环视频以环境图为首尾帧制作，无人物与动作绑定 |
| `cinematic` | 身份 + 造型 + 环境 + 动作整体组合 | 完整场景影像；直接作为主画面，不强制透明处理 |

动作定义是语义层，一个动作可拥有多个媒体实现（不同造型/不同形式）；动作详情经 `by-action` 端点查询已制作清单。不同造型不默认共用同一角色视频。

## 成品与任务

用户组合制作经 `workflows/visuals_companion.py` 冻结已有素材，图片/视频共用现有工作项。原件分析期间使用 `source.kind=analysis` 暂存，完成后转为普通的 actor/scene/cinematic 来源；收藏资格与自动演出资格分开，上传和生成共用成品模型与规则。实际检查及同步发布、重试、原件保护语义归 [影像契约](../../../docs/PROTOCOL.md#影像成品与模式隔离)。分析结果由 `visual_import_jobs` 持久保存，原件和已分析版本共用既有成品与版本附件；分析发布归 `import_publication.py`。

调用方装配三类资产的冻结输入，动作语义及呈现选择来源须按契约完整保存；读取和恢复共用结构校验。本模块不跨域读取素材 ORM。请求身份与冻结输入分别去重；手动制作由客户端保留请求身份，响应丢失后沿原请求核对，不能重新付费提交。环境静态图直接复用环境素材，受理端只制作环境循环视频，制作请求可带可选 `day_phase` 冻结适用时段：复用可恢复图片链先准备对应光线的起始图，再设计环境循环；复核同时读取原环境、起始图与视频抽样；它与角色视频共用队列、候选选择和恢复流程，按环境抽样复核，不做人物身份评分。导入关联修改会保留本次创建过的素材归属；撤销或切换前由 workflow 检查影像、生活和当前任务引用，仍被共享时只解除本次关联，不删除素材。

`publication.py` 组合业务采纳与公共任务完成守卫，核对目标和预期版本后追加不可变版本、切换当前指针并登记资产；调用方在同一采纳事务经 `life.py` 结算关联步骤。完整场景和环境视频可先采纳起始图，主体动画只保留真实输入图的文件引用，不创建主体图片成品。重做失败、暂停或取消保留旧成品。

生成主体视频按固定帧率逐帧抠像；原生透明的用户视频保留实际 alpha 并作逐帧检查，二者都用确认后的 RGBA 帧编码 WebM，原件另存；遮罩时间与交付视频对应，首末帧、遮罩及锚点写入版本 `body_json`，并以版本附件保护文件。边界和底部支撑锚点来自真实 alpha，头部锚点随视频复核读取实际首帧，无法确认则留空。处理链见 [actor_clip.py](../../infrastructure/video_processing/actor_clip.py)。自动使用的文件、合成数据与语义资格统一由 [eligibility.py](eligibility.py) 校验；成品检查依据随冻结快照保存，任务检查点回收不清除该依据。

基础准备由 [visual_preparation.py](../../workflows/visual_preparation.py) 协调：只为已采用造型（首次无呈现时取初始造型）准备内置基础动作，先完成默认待机循环，成功后按固定顺序渐进补充互动反应与常用循环（准备集与顺序以该文件常量为准）；先复用身份、造型及动作版本相符且已确认可自动使用的成品。制作完成不等于可自动演出：成品照常保留在影像库，只有实际语义确认合格才计入该动作的准备；待机循环没有合格成品时结束本轮，渐进动作的不可自动使用只记录原因并继续后续动作。任一项失败、暂停或未知终止本轮并留给原任务恢复入口，同一请求不重复付费。工作项来源 `base_preparation` 与自主制作分开，不读取生活策划资料、不创建生活步骤或经历，共用现有有限修复与供应商预算。实际身份、造型图片与动作内容派生稳定请求身份，描述更新、重启及重复通知不重置额度；新造型仅入柜不触发准备，实际采用、首次就绪与维护恢复才请求准备。

制作按工作项单飞，视频阶段接入公共队列；共享供应商等待与未知结果规则归 [PIPELINE](../../../docs/PIPELINE.md#全局视频队列)。业务保留自己的采纳条件，不改写调用方的生成要求。

## 呈现与文件

呈现读取指定的冻结版本，素材修改或重做不能追改已显示的事实。呈现行保存舞台组合 `composition_json`（layered 引用环境层与主体层 / cinematic 整片引用，互斥）与生活意图 `intent_json`（生活侧只写投影，含结构化活动类别，呈现系统只读取）；两者是呈现配置，不构成第二份生活事实。组合携带持续画面的选择来源 `selection_source`（base/life/user）：开播回执按播放账本登记的来源推进组合——生活导演选择的持续整片记录选择时的生活修订与活动类别，用户/伙伴点播记为 user，普通轮换与恢复回落 base；客户端据此在意图变化时重新核对 life 画面（不再匹配则退出回基础舞台，同活动沿用不重复派发），user 画面不受普通生活更新影响。恢复沿组合既有来源继承，恢复动作本身不重置。呈现响应在 `composition.media` 附各层可播媒体投影（含 actor 版本的 `body` 锚点与命中元数据），播放指令对 actor 成品同样携带 `body`；`ambient_actor` 从已有且可自动使用的待机成品中匹配冻结身份和造型，`ambient_catalog` 另投影当前身份与造型可用的主体动画与完整场景影像（含冻结动作属性、实际媒体语义及适用条件）；目录只收录已确认可自动使用的成品，每份成品取最新的合格版本，内置动作按用途各留一份，各版本独立判定资格。常驻主体、一次反应与完整场景分别限额，内置动作各占一格。`ambient_scene` 独立投影环境层可播媒体（按当前环境的冻结内容筛选，各时段保留最新可播环境视频，静态回退直接使用舞台冻结素材），供客户端导演按活动类别结构化匹配并本地选择常驻轮换与环境时段版本，三者不制作新素材、不建立逐圈播放账本；窗口模式播放透明主体视频按 `video` 回执并推进组合，静态投影仍按 `window_static`。客户端导演点播（`POST /{visual_id}/play?version=...`，desktop 身份）走同一指令管线，按目录指定版本登记播放与回执；`origin` 区分 user 点播与 life 生活导演选择，life 请求携带选择时的 `life_revision`，受理时复核意图有效性、自动资格及舞台冻结身份、造型。

生活情境投影与静态兜底归 [life_presentation](../../workflows/life_presentation.py)：动态表现关闭或无可播媒体时生活变化只落到静态目标，自主播放与制作受主动档位及自主开关约束。

`notify_visuals_updated` 通知库、任务和生活意图投影变化，但不推进呈现修订；正式呈现经 `touch_presentation` 及回执推进，制作进度和意图刷新不能使在途播放认领失效。

静态呈现冻结已有素材，不创建影像成品。上线、重连及模式变化通过 `companion_signal` 恢复：事务内重绑当前生活修订及新请求身份，成功才消费在线代次；有效待播指令优先，并发恢复复用已有目标。窗口宿主不接收完整场景恢复指令，改由当前身份与造型可用的透明主体或静态目标承载；生活持续画面仍先按当前意图核对。缺少素材只产生准备状态，不记录为已显示伙伴。

内部快照保留裸路径，HTTP 与事件出口统一经 `client_assets.py` 转换地址且不修改冻结来源。列表使用摘要与 ID 游标，可播目录在数据库筛选；回收核对当前版本、舞台组合各层版本、呈现、播放和任务引用，保留范围见 [必要历史](../../../docs/DATABASE.md#必要历史)。

## 恢复与验证

恢复先重映射物理关系和冻结素材（判别联合按 `source.kind` 分支重映射 outfit/scene/action 引用），再重映射组合各层成品身份并重建呈现快照、作废旧指令与回执；组合媒体投影不随备份恢复。已删除来源保留描述和文件、来源 ID 留空，避免误绑定新库身份；历史成品仍可查看，重做使用当前有效角色资料。未知提交沿 [备份契约](../../../docs/PROTOCOL.md#备份校验与覆盖恢复) 保留原任务。

按 [Scripts](../../../scripts/README.md) 核对请求重放、共享步骤、发布并发、重做与旧回执、静态恢复、账户/模式切换和资产保护；真实视频接续、图片显示与供应商质量分别验收。
