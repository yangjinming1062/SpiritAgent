# 正式资产生命周期

负责正式文件登记、业务引用交接与 `companion-assets` 回收。访问、签名及保留政策见 [资产契约](../../../docs/PROTOCOL.md#资产访问与缓存)，本页维护并发和删除边界。

## 入口

| 修改任务 | 入口 |
|---|---|
| 元数据登记、资产行锁和账户内路径 | [service.py](service.py)、[models.py](models.py) |
| 活引用与保护范围 | [references.py](references.py)、[contributions.py](contributions.py) |
| 释放待办、文件发现与补偿删除 | [lifecycle.py](lifecycle.py) |
| 业务贡献装配 | [bootstrap/assets.py](../../bootstrap/assets.py) |
| 写入期间保护 | [write_protection.py](../../infrastructure/assets/write_protection.py) |

## 引用交接

正式文件按账户及路径唯一登记，业务通过直接外键或领域关联表持有资产。裸路径仅作展示与冻结输入；消息、外观和声音写入须在 flush/commit 前完成引用登记，不能留下已经写盘但未交接的文件。

写入保护随任务所有者继承，覆盖子工具返回到父回合提交的间隔；独立后台任务须有自己的所有者，非协程写入显式释放保护。派生历史和复制旧引用持同一用户资产锁。每个业务模块经 `asset_references.py` 提供引用、保护、清理及遗忘贡献，汇总层不读取外域 ORM。

## 回收与失败

删除历史先由 [asset_releases.py](../conversation/asset_releases.py) 在事务内登记释放、移除媒体事件；行锁顺序为源消息、视频任务、助手回复。提交后入口停止对应媒体任务再清理，回滚不删除正式文件。

清理在用户资产锁内以 `SKIP LOCKED` 认领有限批次，再按 READ COMMITTED 重查引用和写入保护。持资产行锁删除文件并提交终态后，才清理业务诊断字段，避免反向等待制作行锁。文件已删而事务未提交可以重试；失败保留次数和诊断。可恢复任务、未知结果、待采纳文件和可重试候选继续受保护。

目录发现仅限账户内指定路径，不跟随符号链接；引用目录不可读时停止该账户回收。显式删除可提前已有待办，提交后补扫，迟到写入由任务完成回调再次触发统一清理。供应商取消归业务所有者，本模块只决定本地文件是否可删。

按 [Scripts](../../../scripts/README.md) 核对回滚、采纳并发、读目录失败、引用交接窗口和删除重试；新增资产类型同时补齐引用贡献与备份。
