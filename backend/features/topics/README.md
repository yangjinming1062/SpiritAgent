# 主动资讯与话题储备

本模块拥有每日采集批次、已验证来源、实际消息的使用记录与独立反馈。夜间流程负责上下文、检索规划及模型精选；采集适配器属于基础设施。本模块返回 DTO，不向调用方暴露 ORM。

## 任务入口

| 改动 | 入口与联动 |
|---|---|
| 批次、来源、使用记录与事务 | [models.py](models.py)、[store.py](store.py)；事务由调用流程提交 |
| 夜间检索、预算与检查点 | [topic_discovery.py](../../workflows/nightly/topic_discovery.py) |
| 聊天资料与来源绑定 | [system_prompt.py](../../workflows/chat/system_prompt.py)、[reply_links.py](../../workflows/chat/reply_links.py)；消息与使用记录原子提交 |
| 反馈与通知 | [use_cases.py](use_cases.py)、[companion_topics.py](../../entrypoints/http/routes/companion_topics.py) |
| 采集源、凭据与内容校验 | [social_sources.py](../../infrastructure/web/social_sources.py)、[social_credentials.py](../../infrastructure/web/social_credentials.py)、[social_content.py](../../infrastructure/web/social_content.py) |
| 备份合并与恢复 | [backup.py](backup.py)；与会话、消息同组恢复 |

## 采集与分享

批次首次建立即冻结 24 小时采集窗口，调用预算在请求之前锁行递增，失败与取消的尝试不退还预算。采集检查点支持中断恢复，发布完成后原子清除完整候选和上下文，只保留精选来源及统计。来源必须有可靠发布时间、文字依据及对应平台内容 ID 的 HTTPS 原文链接。各平台失败相互隔离，空结果也可以形成当日空批次。

新候选只供开启主动资讯的陪伴域读取，按批次可用时间与失效时间过滤。此前实际分享过的来源可凭使用记录继续读取，关闭开关、跨日或清理原消息不会抹去已分享事实。消息提交使用服务端冻结的上下文授权时刻校验来源，允许模型等待期间跨过失效时刻；这个时刻不能来自模型输出。使用记录与消息在同一事务提交，沉默、取消及失败不会制造分享记录。

聊天只装配本会话清空水位之后的历史来源，摘要不删除引用；按当前话题相关性补充最多五条已分享资料。原始正文与字幕保存在来源表，单次聊天各提供最多 6000 字符并标明摘录，保留完整事实摘要及发布时间。链接卡片从服务端来源快照绑定，恢复时核对快照与来源一致。

反馈只允许操作本账户本陪伴域已分享的来源；状态和 outbox 通知共同提交，不触发聊天。未反馈与撤销保持未知，下一夜同时读取来源、使用时间、显式反馈及真实对话证据。

## 备份与恢复

备份把会话、消息与话题四表作为同一恢复分组，先恢复批次和来源，再恢复消息及使用引用。合并前在真实目标账户核对同日批次的固定采集时间、可用期和完成状态，以及合并后的每日五条上限；冲突只拒绝该分组，其他可恢复类别继续处理。重复来源须保持原文、字幕、发布时间与链接等来源快照一致，保留目标已有模型摘要及兴趣判断，不因衍生描述不同拒绝幂等合并。

清理旧消息时使用记录的消息引用置空。恢复合并对有消息引用的使用记录按来源与消息去重，对已清理消息的记录按来源与实际使用时间保留独立证据，重复导入不会丢掉最近使用时间。恢复时清空采集检查点，采集中批次转为失败；可用时间原样保留，过期批次不会重新成为新候选。

## 采集源与网络边界

社交内容契约与原文地址校验不依赖采集供应商。默认免费源覆盖 X 与小红书：X 使用运维提供的 `auth_token`、`ct0` Cookie，固定调用 X 查询接口，只使用固定版本 twscrape 的操作定义和解析器，不建立账户池或自动登录；小红书读取运维自托管服务，首次确认登录状态后缓存至本次夜间采集结束。小红书搜索卡片没有可靠发布时间，必须补充详情才可入选。免费源不支持抖音，不自动退回收费源。部署与登录操作见 [免费社交资讯来源](../../README.md#免费社交资讯来源)。

Backend 每次来源接口 HTTP 请求之前执行夜间闸门和预算回调，包括小红书首次登录状态查询及 X 网页签名初始化；自托管浏览器内部的页面资源请求不在 Backend 接口计数中。X 使用固定版本 SDK 从网页和静态脚本生成 `x-client-transaction-id`，本次夜间采集内缓存生成器；初始化也可能耗尽调用预算，此时允许没有结果。初始化只读取 `x.com` 和 `abs.twimg.com` 的 HTTPS 资源，Cookie 仅发送给 X，跳转逐次校验和计数。适配器自身不重试。

自托管服务只允许固定的运维配置 origin，私网豁免不扩散到原文地址或模型 URL，元数据、链路本地地址和重定向仍被拒绝。可选 TikHub 凭据只发给官方 HTTPS API 域名。解析保存正文、描述和响应内现成字幕文字，字幕 URL 不当作已读取字幕；不下载或分析视频画面。真实来源验证需有效的运营登录或供应商额度，文档与模拟响应不能证明平台字段完整性或原文链接可达性。
