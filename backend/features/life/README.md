# 生活状态

账户只有一份生活状态；`LifeContext` 是聊天、影像、动态、夜间和日记共同读取的冻结只读快照；`LifeEvent` 保存可核验的状态变化，`LifePursuit` 保存跨天事项，`LifeStep` 只关联业务任务，不复制业务模块状态机。持续事项和步骤使用账户内幂等键，重复受理返回既有记录。

步骤完成只推进所属事项，写入进度和下一步，不隐式完成 `LifePursuit`。有意义事件由装配层投影为伙伴自身的 `recall:life:*` 记忆，事件表仍是事实来源，投影失败不能伪造业务成功。

模型等待发生在事务外，提交时按状态 `revision` 乐观校验。事件以账户和 `event_key` 幂等，重复结果返回已有事实而不再次推进状态。HTTP 仅公开只读查询；生活判断和结果接纳经 `service.py` 的公开入口写入。
