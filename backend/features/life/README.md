## 内部约束

共同上下文保证聚焦事项不被分页挤出；完成判断另读未解决步骤、事项成果和本账户已发布的近期成果，按内容核对发布记录与目标的关系。`prompt_payload` 只投影内容、时间、叙事和结构化失败类别，不携带原始执行诊断、执行参数或存储元数据。用户生活接口使用公开叙事投影，执行层使用内部步骤视图；两者不能互相替代。事项、事件分别按更新时间、发生时间加 ID 稳定分页，总数显式请求才查询，模型上下文不走带总数的管理列表。

生活判断保存 `activity_type` 和当前环境、物品的 `scene_tags`，环境变化未提供标签时清空旧条件。语义、心情或场景变化推进呈现修订；真实步骤认领按能力设置活动类别，结束、暂停或退回等待时撤销正在进行的活动语义并通知投影。视觉选择只读取这些资料，不改变执行或结果事实。

`commit_decision_in_session` 在调用方事务内保存状态、事项、结构化下一步、伙伴叙事、事件与 outbox。叙事由模型在对应操作中提供，程序不通过关键词过滤或静态模板补写伙伴表达。步骤创建、认领、结算共用账户生活状态锁；业务受理再经 `require_step_submission` 检查，采纳事务批量结算关联步骤。模型和能力调用在事务外。

生活判断先持久认领判断身份，并留存失败恢复期限。分享与成长草稿单独审阅。这一步未取得结论时保留已经核实的独处经历，分享和新增认识等待后续判断。伙伴可把下次整体复查定在二十分钟至七天后，新的已确认成果可提前唤醒。只调整某个事项的恢复时间时使用该事项的期限。独处片段提交核对认领身份、修订、作息和前序事件，成果按实际业务引用和所属事项去重。制作暂停释放执行资格，继续前按原请求重取执行位，并在同一事务恢复步骤的活动呈现。

自主事项和独处事件默认私有。模型可从有依据的经历选一段内容，单独写下允许给生活页、动态、日记或直接交流使用的摘选，并可显式允许当前活动进入舞台。生活页检索、详情和更新通知使用公开投影；创作入口只拿到该渠道获准使用的内容。用户参与的约定与任务沿原接口保留。私下制作的范围随受理、执行、文件与后台恢复传递。公开文字摘选和公开原件分别授权，公开原件复用原制作身份与版本。

生活判断复用聊天的人设、用户资料、关系背景和记忆召回。每条兴趣、观点、习惯或边界都有独立标识和来源经历。上下文按主题和近期变化选取各方面的认识，公开创作使用相处倾向。来源删除级联撤销该条认识，用户事实由记忆域独立维护。

日常与夜间共用 `actions.py` 的行动契约、`execution.py` 的受理入口，以及 `life_capabilities.py` 的能力政策与素材快照；执行前复核复用同一政策，规划不各自推断权限或素材。夜间计划项与步骤在同一事务关联，执行状态、结果及完成事件只由步骤保存；扫描读取原步骤续行，不另存执行结果或持续轮询。夜间动作只关联规划明确指定的已有事项，不自动挂到当前聚焦事项。联系安排同样通过步骤认领，Cron 创建与步骤完成在同一事务提交。

有意义事件在本域保存独立检索文本，覆盖叙事、受控事实和关联阅读笔记，不直接写入认知记忆。`search.py` 提供账户隔离的关键词/向量混合查询与公开、模型两种投影；日期范围按账户本地日解释，向量失败退回关键词。检索文本随事件写入和恢复建立；保存点隔离索引失败并按事件保留成功项，关键词查询按需补齐缺失索引，失败不撤销生活事实；向量通过受监督单飞任务在事务外生成，写回复核内容指纹、模型与维度，维护及停机取消任务。跨模块通过公开操作和 DTO 协作。执行失败写入结构化 `failure_code`，原始诊断只留在任务和日志边界；已取得成品地址但下载失败的视觉步骤保留为 `unknown`，沿原任务恢复，不创建第二个步骤。

受理记录保留原请求的提交事实，已认领但尚未提交的步骤沿原请求续行，结果未知时核对原任务。阅读正文与实际范围保存在永久成果中，公开详情只返回叙事、笔记、来源和摘要。数据库迁移基线见 [迁移序列](../../alembic/versions/0001_baseline.py)。

## 来源与阅读上下文

聊天模型判断本次操作是否来自用户的明确指令。`life_adjust.user_instruction` 必填：用户要求时逐字引用，伙伴自行调整时为 `null`；待确认的要求不能按自主决定执行。入口按受理顺序读取本批已保存的用户消息，逐条核对原文，按实际匹配的消息 ID 登记来源。语义审阅结合整批发言及后续修正；有效引用才标记 `source=user`。引用留在工具调用记录，不进入领域决策字段。原文匹配只核对出处，操作与目标的语义判断仍由聊天模型负责；领域层继续检查用户暂停、修订和请求幂等。同一发言的多项明确约定分别按标题和可核验目标登记，重复调用复用原请求。

日间阅读规划分别核对已保存的资讯、网页搜索和正文提取。执行时复用已取得的原文，按实际需要复核外部工具。阅读关联到具体事项时补充该事项的结果证据，无关联事项时使用当前背景和阅读目的。笔记保留动机、所得、与已有认识的关系及未解问题。早先的阅读可以启发新事项，更新完成进度须引用该事项的实际结果或可核对的独立发表作品。笔记沿成果、事件和历史检索进入后续选择，伙伴决定是否分享。

## 验证边界

事务、幂等、来源、暂停与恢复用隔离数据库核对。否定、引文、目标歧义以及阅读对后续选择、聊天和日记的影响，用真实模型保留原始输入、选择与实际交付。连续相处的感受按[持续生活验收](../../../scripts/README.md#持续生活验收)另行观察。
