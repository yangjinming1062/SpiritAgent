# 动作素材

拥有独立的动作语义定义与评审状态：动作内容、适用条件、持续 loop／短 once 类型与时长。定义不绑定衣柜、环境或成品影像，同一动作可被不同组合使用，具体环境与道具是否满足动作要求在组合制作时判断。登记定义本身不启动图片或视频制作。名称只用于展示和检索，不承担跨来源唯一身份，内容不同但名称相同的定义各自独立。全局语义归 [动作素材与影像播放](../../../docs/PROTOCOL.md#动作素材与影像播放)，定义与评审规格归 [PIPELINE](../../../docs/PIPELINE.md#动作素材定义与评审)。

## 评审与恢复

评审依据为角色身体能力与动作含义，随定义冻结保存。评审可批准、暂缓或拒绝；同一账户内同名且内容相同的重复提交通过账户内动作领域锁收敛，复用已有定义。模型提交前持久记录评审中，中断转为暂缓、需手动重试，不自动重新付费。编辑动作回到待评审，不追溯已生成影像，也不触发批量重做。

备份按定义整体校验与恢复，冻结评审参考随行保留；未完成评审恢复为待手动继续，恢复不启动付费制作。冻结评审参考独立持有资产引用，来源删除后仍保持引用。

列表按 ID 游标分页，总数按需读取；摘要查询不加载冻结评审资料。桌面与远程搜索直接过滤服务端结果，更多结果沿返回游标继续读取；模型检索工具返回相同的分页标志。
