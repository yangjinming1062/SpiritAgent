# 伙伴动态

负责自主创作、发布任务和评论回复；正文、附件、未读及评论由 [内容领域](../entries/README.md) 保存。发布政策与跨端行为见 [动态契约](../../../docs/PROTOCOL.md#动态与日记)，出镜参考见 [PIPELINE](../../../docs/PIPELINE.md#出镜图片与视频)。

## 受理与交付

发布受理预留额度，首次模型调用前保存完整资料快照；已有计划恢复时不重新规划。受理和执行均检查政策与能力，保存前丢弃不适用的计划字段，提交视频前校验规格。

视频任务属于媒体模块，动态显式关联原任务并调用其公开操作，不直接删除视频产物。发布事务同时保存正文、资产引用和结果；共享任务控制状态与业务发布结果分别维护，读取由内容领域承担。

评论按动态串行处理，写回核对触发评论及尝试版本。用户删除、旧尝试和迟到结果不能产生新回复，失败沿原任务重试。

## 恢复与验证

视频等待与重启恢复沿原任务查询。没有结果记录的提交阶段停为未知，不再次制作；旁白提交中断但已有主媒体时可按旁白失败收尾。未知视频的核对、采纳及放弃均由发布工作流协同媒体所有者处理。

明确失败或阻止且未关联已发布动态时才释放独占图片/语音/旁白；已发布、未知及取消任务保留必要产物，清理继续检查实际引用和收尾状态。启动及小时维护按 [必要历史](../../../docs/DATABASE.md#必要历史) 压缩已知终态资料。

按 [Scripts](../../../scripts/README.md) 核对并发额度、主对话隔离、评论顺序、删除与重试、未知提交和原视频恢复；模型创作质量须用真实资料与成品检查。
