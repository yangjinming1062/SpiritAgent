# 伙伴动态

负责自主创作、发布任务和评论回复；正文、附件、未读及评论由内容领域保存。

## 关键入口

| 修改任务 | 入口 |
|---|---|
| 低频决策入口与候选账户 | [autonomous.py](autonomous.py) |
| 资料快照、制作、原视频核对与采纳 | [publication.py](publication.py) |
| 发布请求与事务 | [store.py](store.py)、[publication_models.py](publication_models.py) |
| 创作/评论背景及输出约束 | [context.py](context.py)、[prompt_contract.py](prompt_contract.py) |
| 评论线程回复 | [replies.py](replies.py) |
| 启停、恢复与清理 | [lifecycle.py](lifecycle.py) |

## 受理与交付

按账户在同一事务内查找或创建规划中的发布任务。并发扫描与恢复按同一任务 ID 调度。计划保存后，媒体制作与下一次规划可独立进行。首次模型调用前保存完整资料快照，已有计划恢复时按原计划继续。受理和执行均检查政策与能力，保存前丢弃不适用的计划字段，提交视频前校验规格。

视频任务属于媒体模块，动态显式关联原任务并调用其公开操作，不直接删除视频产物。发布事务同时保存正文、资产引用和结果；共享任务控制状态与业务发布结果分别维护，读取由内容领域承担。

评论按动态串行处理，写回核对触发评论及尝试版本。用户删除、旧尝试和迟到结果不能产生新回复，失败沿原任务重试。

## 恢复与验证

发布任务在等待视频时登记依赖并退出执行。终态通知与启动核对都沿原任务继续，提交前核对原授权、当前开关、身份和成品证据。主媒体无可用版本时收尾，结果未知时继续核对同一供应商尝试。

近期纠偏候选与原始判断按七天任务保留期供诊断，文件回收同时检查已发布、在途和共享引用。

核对独立发布、重放去重、主对话隔离、评论顺序、删除与重试、未知提交和原视频恢复；模型创作质量须用真实资料与成品检查。
