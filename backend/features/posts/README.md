# 伙伴动态

编排独立主动创作、线程评论回复和后台任务。共享背景、时间窗口、发布额度、未读及结果未知的完整语义归 [PROTOCOL](../../../docs/PROTOCOL.md#动态与日记)，出镜媒体参考归 PIPELINE。

## 入口与所有权

| 入口 | 职责 |
|---|---|
| [publication.py](publication.py) | 额度预留、创作前资料快照和媒体制作，原视频核查/采纳/放弃及记录回收 |
| [context.py](context.py) | 创作与评论共用背景、动态制作资料和事件时间 |
| [replies.py](replies.py) | 每动态串行生成评论回复，写回核对触发评论及尝试版本 |
| [autonomous.py](autonomous.py) | 已初始化活跃账户的低频决策，按用户单飞 |
| [prompt_contract.py](prompt_contract.py) | 共用 schema 生成模型可读约束 |
| [store.py](store.py) | 发布事务、额度、评论和夜间线程归集 |

任务启停经本模块生命周期贡献在 bootstrap 登记，周期恢复随 Cron 扫描；所有后台任务登记账户归属，纳入账户维护。视频制作与文件归 `features/media/video_jobs`，发布通过显式 `video_job_id` 关联并调用媒体操作，不能直接删除视频产物。

## 制作与恢复

[PostPublication](models.py) 受理时预留额度，首次创作调用前装配并保存完整资料快照，有计划不重新规划。计划中不适合内容类型或实际能力的字段保存前丢弃；视频规格在提交前校验。受理和执行均重新核对政策与能力。

- 视频持续等待原任务的确定终态，重启后沿已保存任务继续。没有结果记录的 `*_submitting` 按未知提交停止；`narration_submitting` 已有主媒体时可按旁白失败收尾。
- 明确失败或阻止后，任务没有关联动态才释放独占图片、语音和旁白；已发布、未知及取消状态保留必要产物。发布状态和媒体引用须一起提交。
- 视频未知结果保存为 `result_unknown`，保留原计划、任务与资产；查询核对原任务、下载原结果并完成必要检查，不启动新的视频生成。合格结果经发布服务重查身份、政策与额度后自动发布，低分和检查缺失不能人工放行。放弃仍协同视频所有者回收引用。
- 评论线程在写回前核对触发评论和尝试版本，删除与旧尝试不能产生迟到回复；失败沿原任务重试。

发布状态使用 [PostPublicationResult](schemas.py)；夜间只归集实际动态与评论，不以受理当成发布。

## 记录保留与验证

`gc_autonomous_publications` 回收已知终态任务：完整输入/计划七天，精简审计九十天。未知结果、检查尚未完成、在途视频及待完成资产清理保留，已发布内容的媒体归属字段继续保留。启动和小时维护调用回收。

命令归 [Scripts](../../../scripts/README.md)。重点核对主对话隔离、线程顺序、删除与重试、并发额度、未知提交、原视频恢复及长媒体评论；模型创作质量与静态检查分开报告。
