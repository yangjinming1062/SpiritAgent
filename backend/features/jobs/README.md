# 持久任务

拥有请求幂等、任务资源引用和通用执行控制的公开操作。业务继承 [JobRecord](../../infrastructure/job_models.py)定义自己的详情。

通用层管理执行状态、修订、取消及检查点，各业务决定恢复、结果采纳和完成条件。ORM 写入维护修订和开始／结束时间，批量操作须显式维护；取消意图不能代替清理完成。

`job_requests` 保留请求幂等身份，清理保留身份与终态，不能因检查点释放而重复执行请求。`job_assets` 在业务事务内登记，普通临时引用随终态保留期释放；长期资料使用 `service.py` 的保留角色，由业务精确替换引用或随任务删除释放，不受检查点保留期影响。实际文件删除归资产模块，写入保护覆盖引用交接之前的窗口。

恢复通过物理父表和详情表重建；共享层不擅自重投未知提交，也不直接读取其他业务详情。
