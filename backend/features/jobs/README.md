# 持久任务

拥有请求幂等、任务资源引用和通用执行控制的公开操作。业务继承 [JobRecord](../../infrastructure/job_models.py)定义自己的详情，ORM 边界归 [Backend](../../README.md#模块依赖边界)，字段关系见 [任务字典](../../../docs/DATABASE_FIELDS.md#任务与资产)。

通用层管理执行状态、修订、取消及检查点，各业务决定恢复、结果采纳和完成条件。ORM 写入维护修订和开始／结束时间，批量操作须显式维护；取消意图不能代替清理完成。

`job_requests` 保留请求指纹并支持多个请求共用制作；清理遵循 [必要历史](../../../docs/DATABASE.md#必要历史)，不能因检查点释放而重复执行请求。`job_assets` 在业务事务内登记，任务清理只释放引用，实际文件删除归资产模块；写入保护覆盖引用交接之前的窗口。

恢复通过物理父表和详情表重建，导入执行状态及供应商句柄按 [备份契约](../../../docs/PROTOCOL.md#备份校验与覆盖恢复)处理。共享层不擅自重投未知提交，也不直接读取其他业务详情。
