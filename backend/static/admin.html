创建用户

嵌入激活码的后端地址，用户激活时客户端将连接此地址。
激活令牌仅以哈希存储，无法再次查看原码。重新生成将创建新激活码（旧码立即失效）并在此展示。

导出用户备份

包含角色与形象、衣橱、房间背景、用户画像与设置、音色、长期记忆、片刻、日记和定时任务。

默认不包含会话记录。备份包含用户 API 凭据，请妥善保存。导入后请重新启动客户端以刷新数据。

导入用户备份

导入目标用户 #。恢复备份中包含的角色、形象与衣橱、房间、设置与凭据、长期记忆、片刻、日记和定时任务；仅当备份包含会话记录时才恢复会话。未包含的会话保持不变。导入后请重新启动客户端。

支持本后台导出的 ZIP；旧备份未包含的内容无法补回。

激活码已生成

请将此激活码发送给用户，用于客户端激活。

激活码管理

激活码携带后端服务地址与用户认证令牌。您可以在此随时查看当前激活码并复制发放。后端地址变动时输入新地址点击「更新后端地址」即可，无需重置令牌；如需强制作废旧激活码可点击「重新生成激活码」。
更新后端地址会自动重打激活码，不影响用户已有数据与授权。

配置凭证

用户能力链有卡片时覆盖系统能力链；空链继承系统配置。用户能力卡片可继承用户或系统的同名供应商信息。
