创建用户

嵌入激活码的后端地址，用户激活时客户端将连接此地址。
重新生成会创建新激活码并在此展示，旧码立即失效；当前激活码可随时在用户列表的「激活码」中查看。

导出用户备份

导出为全量数据：角色与形象、角色卡、衣柜与动作、场景、用户画像与设置、音色、长期记忆、动态、日记、定时任务和会话记录。

恢复时可在导入对话框选择范围（如仅基础身份）。备份包含用户 API 凭据，请妥善保存。导入后请重新启动客户端以刷新数据。

导入用户备份

导入目标用户 #。只恢复勾选范围内的数据，不动目标已有但未勾选的内容。各类数据会尽力恢复，不兼容的内容将在完成后列出。旧备份中的片刻表会静默忽略，视为没有动态。导入后请重新启动客户端。

恢复人设与音色、头像与全身形象（含确认状态）、角色卡。写入空用户后无需再走引导。
支持本后台导出的全量 ZIP；旧备份未包含的内容无法补回，损坏或校验失败的 ZIP 不会导入。

激活码管理

激活码携带后端服务地址与用户认证令牌。您可以在此随时查看当前激活码并复制发放。后端地址变动时输入新地址点击「更新后端地址」即可，无需重置令牌；如需强制作废旧激活码可点击「重新生成激活码」。
更新后端地址会自动重打激活码，不影响用户已有数据与授权。
